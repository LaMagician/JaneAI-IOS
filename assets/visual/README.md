# JANE ION Visual Asset Package

This package defines the first cohesive visual identity for JANE ION: cinematic black graphite surfaces, metallic silver structure, electric-blue energy, subtle violet depth, and restrained holographic motion.

## Assets

- `branding/jane-ion-logo.svg` - official full logo and wordmark.
- `branding/jane-ion-mark.svg` - transparent brand mark for icons and compact UI.
- `branding/jane-ion-splash.svg` - static splash-screen composition.
- `branding/jane-ion-icon.png` - 512 px application icon generated from the mark.
- `avatar/jane-ion-avatar.svg` - holographic female AI presence.
- `core/jane-ion-core.svg` - animated AI core and state language.
- `boot/jane-ion-boot-sequence.svg` - animated boot-up sequence.
- `loading/cognitive-loading.svg` - rotating neural loading animation.
- `backgrounds/jane-ion-neural-field.svg` - subtle command-center background.
- `ui/holographic-hud-elements.svg` - reusable HUD frames and rings.
- `effects/state-indicators.svg` - state indicator sheet.
- `effects/scanning-particles.svg` - scanning, data, and execution effects.

## Direction

Use the logo mark as the strongest identifier. Use the core as Jane's active presence during processing, listening, speaking, and idle states. Keep backgrounds very dark and quiet so terminal and chat content remain readable.

Animation should feel purposeful: slow breathing for idle, ring rotation for thinking, waveforms for listening and speaking, scanning beams for execution, green-blue confirmation for success, and controlled amber for warning.
