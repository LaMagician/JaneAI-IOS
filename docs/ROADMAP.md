# Roadmap

1. Bootable deterministic prototype. **Complete**
2. Host human interface with offline STT/TTS. **Complete**
3. Auditable requests, path policy, first-boot identity, replaceable backend boundary. **Complete**
4. Versioned skill registry and system-context tools. **Complete**
5. Persistent state disk, bounded memory retrieval, confirmation prompts, and supervised recovery. **Complete**
6. Hardware-adaptive low-end profiles and CPU-first voice/context limits. **Complete**
7. Real local and remote pretrained model adapters.
8. Multi-step planner with checkpoints, bounded retries, write verification, and file-action rollback. **Complete for current tool set**; external side effects remain non-rollbackable by design.
9. Privilege-separated services and crash supervision.
10. Jane-centered desktop shell, notifications, and application context.
11. Installer, upgrades, recovery mode, hardware detection, and release automation.
